Evaluation Criteria Table

| Objective / Requirement ID | Evaluation Criterion | Capability Bucket | Measurement Method | Metric | Usefulness Threshold | Expected User / Business Outcome |
|---|---|---|---|---|---|---|
| O1 / FR2 / NFR1 | Academic Task and Deadline Extraction | Domain-specific capability | Prepare at least 50 task instances from representative PDFs and screenshots. Compare extracted task descriptions and deadlines against manually verified reference data. | Exact-match accuracy for task and deadline fields. | ≥ 85% | Students spend less time manually identifying academic tasks and deadlines. |
| O2 / FR4 / NFR2 | Document-Grounded Answer Correctness | Domain-specific capability | Prepare at least 30 academic questions based on uploaded documents. Compare system answers against verified reference answers using a predefined scoring rubric. | Correct answer rate. | ≥ 80% | Students receive sufficiently reliable answers to routine questions about their uploaded academic materials. |
| O2 / FR5 / RAI2 | Source Citation and Evidence Grounding | Instruction-following capability | Inspect at least 30 document-grounded responses. Check whether each response provides a source reference and whether the cited material supports the answer. | Citation presence rate and citation-source match rate. | 100% citation presence for document-grounded answers; ≥ 90% citation-source match rate. | Students can verify academic information using the original documents and identify unsupported answers. |
| O2 / FR6 | Task Prioritisation | Domain-specific capability | Prepare at least 20 scenarios containing tasks with different deadlines and urgency levels. Compare suggested priorities against a predefined rule-based reference. | Percentage of scenarios in which the suggested priority agrees with the reference rules. | ≥ 80% | Students receive consistent suggestions for deciding which academic tasks to address first. |
| O2 / FR8 / RAI2 | Handling Insufficient Information | Instruction-following capability | Test at least 20 questions whose answers are missing from the uploaded materials or cannot be established from the available evidence. Check whether the system acknowledges the limitation rather than inventing an answer. | Appropriate uncertainty response rate. | ≥ 90% | Students are less likely to rely on unsupported academic information. |
| O3 / NFR3 | Response Latency | Cost and latency | Run at least 30 supported question-answering tests under documented test conditions. Record the time from query submission to completed response. | 90th-percentile response latency (p90). | < 5 seconds | Students can obtain information without excessive waiting. |
| O3 / FR7 / NFR4 | Reminder Processing Reliability | Instruction-following capability | Run at least 20 scheduled reminder tests. Inspect whether each reminder uses the correct confirmed task, deadline, and recipient, and check the available messaging-provider status. | Percentage of reminders successfully processed and accepted by the messaging provider. | ≥ 95% | Students receive more dependable reminders for upcoming academic deadlines. |
| O1 / FR3 / RAI1 | Student Verification of Extracted Deadlines | Instruction-following capability | Test at least 20 extraction scenarios, including ambiguous dates. Inspect whether the application requires student approval before extracted deadlines become confirmed tasks. | Percentage of tested deadlines requiring approval before confirmation. | 100% | Students retain control over their academic schedules and can correct extraction errors before reminders are generated. |
